The Cantor set

We will define a subset \(\mathbf{C}\) of \([0,1]\). \begin{gather*} I_1=\left(\frac{1}{3},\frac{2}{3}\right) \\ I_2=\left(\frac{1}{9}, \frac{2}{9}\right), \quad I_3=\left(\frac{7}{9},\frac{8}{9}\right) \\ I_4=\left(\frac{1}{27},\frac{2}{27}\right), \; I_5=\left(\frac{7}{27},\frac{8}{27}\right), \; I_6=\left(\frac{19}{27},\frac{20}{27}\right), \; I_7=\left(\frac{25}{27},\frac{26}{27}\right) \\ \vdots \end{gather*} The Cantor set is defined by removing from the interval \([0,1]\) all the sets \(I_1,I_2,\ldots\): \begin{equation} \mathbf{C}=[0,1]\setminus\bigcup_{n=1}^{\infty}I_n. \end{equation} Sometimes it is more convenient to have a double indexing: $J_{n,k}=I_{2^n+k}$, $k=0,1,\ldots,2^{n}-1$, $n\in\mathbb{N}$. Here, $n$ can be interpreted as the “step” in the iterative procedure of constructing the Cantor set. At the $n$-th step, we remove from $[0,1]$ the sets $J_{n,k}$, $k=0,1,\ldots,2^{n}-1$. Thus, we can write: \begin{equation} \mathbf{C}=[0,1]\setminus\bigcup_{n=1}^{\infty}\bigcup_{k=0}^{2^n-1}J_{n,k}. \end{equation}

The basic properties of the Cantor set

Theorem.
The Cantor set have the following properties:
  1. The Lebesgue measure $\mu(\mathbf{C})$ of the Cantor set equals $0$.
  2. The set $\mathbf{C}$ is uncountable.
  3. The set $\mathbf{C}$ is compact.
Proof.
  1. Observe, that since $\mathbf{C}$ is obtained by removing from the interval $[0,1]$ at the $n$-th step of the construction, the $2^{n-1}$ intervals $J_{n,k}$ of the length $\frac{1}{3^n}$ each, we have \begin{equation*} \mu(\mathbf{C})=1-\sum_{k=0}^{\infty}\frac{2^k}{3^{k+1}}=1-\frac{1}{3}\cdot\dfrac{1}{1-\frac{2}{3}}=0. \end{equation*}
  2. Let $x\in\mathbf{C}$, so we have $x=\sum_{n=0}^{\infty}c_n3^{-n}$, with $c_n\in\{0,2\}$ for any $n\in\mathbb{N}$. We define the function $f$ by the equation \begin{equation*} f(x)=\sum_{n=1}^{\infty}b_n2^{-n}, \end{equation*} where $b_n=\frac{a_n}{2}$, $n\in\mathbb{N}$. It is enough to see, that $f$ maps $\mathbf{C}$ onto $[0,1]$, and so $\text{card}\,\mathbf{C}\geq\text{card}\,[0,1]=\mathfrak{c}$.
  3. Obviously, $\mathbf{C}$ is bounded, as a subset of the interval $[0,1]$. Since $\mathbf{C}=[0,1]\setminus\bigcup\limits_{n=1}^{\infty}I_n=\bigcap\limits_{n=1}^{\infty}\big([0,1]\setminus I_n\big)$ is an intersection of closed sets, it is also a closed set. Hence, $\mathbf{C}$ is compact.
Theorem.
The Cantor set \(\text{ }\mathbf{C}\subseteq[0,1]\) does not contain any open interval. In particular, the Cantor set does not have any isolated points.
Proof. Let $x,y\in\mathbf{C}$, $x\lt y$. We can choose $n\in\mathbb{N}$ such that \(y-x\gt\dfrac{2}{3^n}\). By the construction, there exists $\ell,k\in\mathbb{N}$ with $\ell+1\lt k$ such that \begin{equation*} x\in\left[\frac{\ell}{3^n},\frac{\ell+1}{3^n}\right] \quad \text{ and } \quad y\in\left[\frac{k}{3^n},\frac{k+1}{3^n}\right]. \end{equation*} We have $I_{2^{n}+k}=\left(\frac{k+1}{3^{n}},\frac{k+2}{3^{n}}\right)$ and $\mathbf{C}\cap I_{2^n+k}=\varnothing$. Moreover $I_{2^n+k}$ does not interesect neither of intervals $\left[\frac{k}{3^{n}},\frac{k+1}{3^{n}}\right]$ and $\left[\frac{\ell}{3^{n}},\frac{\ell+1}{3^n}\right]$. Therefore, for any $z\in I_{2^n+k}$ we have $x\lt z\lt y$ and $z\notin\mathbf{C}$. This means, that $(x,y)$ cannot be a subset of $\mathbf{C}$.
Corollary.
The Cantor set \(\mathbf{C}\) is a nowhere dense subset of \([0,1]\).
